# maanas.fyi

Personal site for Maanas Bukkuri — VP of Product, currently building under the *Inflection Point* identity.

## Stack

- Static HTML / CSS / vanilla JS
- Plus Jakarta Sans (Google Fonts) + JetBrains Mono for technical accents
- Dark + light mode (toggle persists via `localStorage`)
- No build step. Deploys directly to Vercel.

## Local preview

Open `index.html` in a browser. That's it.

## Deployment

Auto-deploys via Vercel on every push to `main`.

## Structure

```
/                    Home — hero, approach, work, history, research, contact
/experience          Career index (planned)
  /[role]            Per-role pages with project list
    /[project]       Per-project case studies
/research            DBA thesis + research frame (planned)
/writing             Field Notes essays + retros (planned)
/services            Coaching, fractional, advisory offerings (planned)
```
